# Gradient-Informed Token Merging for Efficient Vision Backbones - reference implementation

## Repository Status

Public release v1.0.0 (15 June 2025).

This snapshot contains the implementation described in the paper
"Gradient-Informed Token Merging for Efficient Vision Backbones". Training scripts live in `src/`, experiment configuration in
`experiments/`, and evaluation notebooks in `notebooks/`.
