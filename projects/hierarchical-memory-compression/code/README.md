# Hierarchical Memory Compression for Long-Context Retrieval - reference implementation

## Repository Status

Public release v1.0.0 (15 June 2025).

This snapshot contains the implementation described in the paper
"Hierarchical Memory Compression for Long-Context Retrieval". Training scripts live in `src/`, experiment configuration in
`experiments/`, and evaluation notebooks in `notebooks/`.
